Answer Key

For the Sage grading the quest
  1. MCMLXXXVI = 1,986 (M = 1000, CM = 900, LXXX = 80, VI = 6)
  2. Treasure chest inventory:
    • 44 = XLIV (40 + 4)
    • XCV = 95 (90 + 5)
    • 360 = CCCLX (300 + 50 + 10)
    • MDCCXII = 1,712 (1000 + 500 + 200 + 10 + 2)
  3. 8,364,572
    • a. Value of the 3: 300,000 (it sits in the hundred-thousands place)
    • b. Ten-thousands place: 6    c. Millions place: 8
  4. 9.628
    • a. Thousandths place: 8    b. The 6 is in the tenths place
    • c. Value of the 2: 0.02 (two hundredths)
  5. Rounding:
    • a. 8.476 to the nearest tenth = 8.5 (hundredths digit is 7, so the tenths place rounds up)
    • b. 8.476 to the nearest hundredth = 8.48 (thousandths digit is 6, so the hundredths place rounds up)
    • c. 2.97 to the nearest tenth = 3.0 9 tenths rounds up and carries into the ones place. Accept 3, though 3.0 shows the tenths place. Watch for 2.10 - that means they rounded the 9 in place instead of carrying.
  6. Reading the runes:
    • a. 5.047 (forty-seven thousandths = 0.047, so the tenths place is a zero)
    • b. three hundred fifteen thousandths
  7. Comparing potions:
    • 0.7 > 0.68 (0.700 vs 0.680)
    • 4.320 = 4.32 (the trailing zero adds no value)
    • 2.109 < 2.19 (2.109 vs 2.190)
  8. The larger hoard is 5,480,279. Both start with 5,4, but the ten-thousands place decides: 8 > 0.
  9. Least to greatest: 3.045 < 3.05 < 3.4 < 3.405 Rewrite to thousandths: 3.045, 3.050, 3.400, 3.405.
  10. Name the property:
    • a. Associative (same order, regrouped parentheses)
    • b. Commutative (factors swapped order)
    • c. Distributive (the 8 is handed to both parts of 50 + 3)
    • d. Identity (adding 0 leaves the number unchanged)
  11. Shortcuts:
    • a. (25 + 75) + (78 + 22) = 100 + 100 = 200 Accept any correct regrouping that reaches 200.
    • b. 7 × (100 + 4) = 700 + 28 = 728
  12. The Great Elixir: 7.490 lb (or 7.49 lb)
    2.375 + 0.840 + 1.006 + 3.250 + 0.019 = 7.490
    Adding zeros so every number reaches the thousandths place keeps the columns lined up.
